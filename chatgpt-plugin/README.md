# MaceChat ChatGPT plugin source

This folder contains the MaceChat character-chat plugin package, separate from the Vite web chat app in the repository root.

## Package contents
- `plugin.json` — plugin metadata and listing details
- `.codex-plugin/plugin.json` — compatible plugin metadata
- `skills/character-chat/SKILL.md` — character-chat behavior instructions

## What it does
MaceChat helps users create original AI characters, start roleplay scenes, run group conversations, and continue stories using the context available in the current ChatGPT conversation.

It is a C.ai-style experience inside ChatGPT. It does **not** connect to Character.AI accounts, import private chat histories automatically, or send messages to Character.AI.

## Version
0.1.1

## Note
This repository copy is source code only. Adding it to GitHub does not publish the plugin in ChatGPT or make it publicly discoverable there. Public listing requires the separate review and publishing process.
